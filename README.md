# ERDIS_Telegram

Bot Telegram che consente di visualizzare il menu giornaliero, orari ecc. delle varie mense ERDIS.

## ATTENZIONE

Ho fatto questo bot con AI (Claude) in cinque minuti, non mi importa che sia scritto bene oppure no, l'importante (per me) è che sia funzionale. Se ci sono problemi di qualsiasi natura segnalateli pure.

## Come installarlo e avviarlo?
Dovete prima creare un vostro bot, a cui verrà associato un token. Potete crearne uno tramite @BotFather.

```bash
pip install "python-telegram-bot>=21" requests beautifulsoup4
export TELEGRAM_TOKEN="token_di_BotFather"
python bot_mensa.py
```
Questo è quanto :)
